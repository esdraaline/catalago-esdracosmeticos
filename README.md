# Catálogo — Esdra Cosméticos

Catálogo de produtos para divulgação e venda (campanhas como Dia dos Namorados, Dia das Mães etc.).

**No ar:** https://esdraaline.github.io/catalago-esdracosmeticos/

## Como é

Página única em HTML (`index.html`) com as imagens em `img/`. Sem build.

## Como atualizar

O fluxo de adicionar produto novo (renomear fotos no padrão e inserir no HTML) é coberto pela skill pessoal **`foto-catalogo`**.

## Relação com os outros projetos da Esdra

| Projeto | O que é |
|---|---|
| **este** | catálogo estático de divulgação |
| `esdracosmeticos` | loja virtual completa (carrinho, checkout, admin, crediário) |
| `agendaEC` | gestão do dia a dia (vendas, entregas, agendamentos, caixa) |
| `financeiroje` | finanças pessoais e do MEI |
